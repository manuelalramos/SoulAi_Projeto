## 💡 Sobre o projeto

O **SoulAI** é uma solução pensada para deixar a experiência dentro da SoulUp mais interativa, personalizada e conectada com ações sustentáveis.

A ideia do projeto é apresentar um avatar inteligente que ajuda o usuário durante o uso da plataforma, trazendo sugestões, missões, interações e recursos que aumentam o engajamento.

O site foi desenvolvido para explicar:

- O que é o SoulAI
- Qual problema ele resolve
- Como funciona a proposta
- Quem faz parte da equipe
- Dúvidas frequentes
- Formas de contato

---

## 🎯 Objetivo

Criar um site institucional e informativo para apresentar o **SoulAI** de forma:

- Clara  
- Responsiva  
- Acessível  
- Organizada  
- Alinhada com a identidade visual da SoulUp
